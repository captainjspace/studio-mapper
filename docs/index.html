The Sourced Script Problem

When you run source script.sh, $0 often refers to the shell itself (e.g., zsh), not your file.

Bulletproof Solution:

local current_script=${(%):-%N}
echo "Running: ${current_script:t}"

C Memory Management

Manual memory management requires discipline. Every allocation must have a deallocation.

Core Functions

malloc(size)
Allocates raw bytes on the heap. Returns void*.
free(ptr)
Releases memory. Crucial: Use once per allocation.
realloc(ptr, size)
Resizes block. May move data to a new address!

Concept: Pointer to Pointer

Why pass char **? So the function can update the caller's pointer address if realloc moves the memory block.

Header Files Strategy

Understand the difference between #import and #include to keep your interface clean and compilation error-free.

Objective-C

Frameworks like Foundation

#import <Foundation/...>

Includes automatic guards.

Standard C

POSIX libs like unistd, stdio

#include <unistd.h>

Manual guards (usually).

Local Files

Your own .h files

#import "MyLogger.h"

Your Public Interface.

The Header Analogy

Header (.h) Like exports in Node.js or public in Java. Defines what the world sees.
Implementation (.m/.c) Like private methods. Contains the actual logic and internal helpers.
